## How I Work

- **Build to learn** — every project is a chance to understand something new, not just add a line to a resume.
- **Ship real functionality** — I'd rather build something small that works properly than something large that's fragile.
- **Own the code** — I use AI as a development assistant, but I make sure I can explain and maintain everything I ship.
- **Keep improving** — currently deepening React and JavaScript fundamentals while learning backend development.
